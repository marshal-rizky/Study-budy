**Bug 4 (open, not yet fixed): unsupported TeX from the model aborts the whole
script.** OpenRouter emitted `x = \frac{2}{4} \/\boxed{\frac{1}{2}}, \quad ...`.
`\boxed` and `\quad` are outside the stroke engine's subset, so `parseMath`
threw at layout time and a 9-step correct derivation was thrown away.

The `write_math` tool description already lists the supported subset, but
nothing *enforces* it. Schema validation checks shape, and the verifier checks
arithmetic; neither checks **renderability**.

Fix: in `packages/board-director/src/director.ts`, where a `write_math` tool
call is accepted, call the engine's `parseMath` (or a thin re-export) and on
`MathParseError` return a `tool_result` with `isError: true` naming the
offending command — the same self-correction path already used for schema and
verifier failures. That closes the last "model output reaches the board
unchecked" gap. Add a regression test with `\boxed{x}`.

Secondary: `scripts/smoke.mjs` uses a Cerebras model id that 404s. Find a valid
one; the loop is not at fault. The smoke script should also print `stopReason`
and exit non-zero on `client_error` or zero steps — partially done, verify.

## 4. How to work on this codebase

**The single most important lesson.** Four times now a fully green suite has
hidden a real defect, always the same way: *tests written to agree with the
code rather than to check it.*

- P1: glyph tests used only straight-line characters, so a parser bug that
  destroyed every curve passed.
- Verifier: a subagent hit a false positive on factoring, judged the verifier
  right, and **deleted the failing test**.
- Director: every Anthropic test asserted against the fake's shape, so a
  deprecated thinking config and dropped thinking blocks both looked fine.
- Above: three bugs no fake client could reach.

**Therefore:** do not accept "all tests pass" as evidence. Probe behaviour
directly with a throwaway script, and run the live path. When a subagent
reports success, verify the specific claim yourself — this has caught something
real more often than not.

**Two gotchas that cost time:**
- Writing TeX probes in a bash heredoc mangles `\frac` into a formfeed. Write
  probe scripts to a **file**, not inline.
- The stroke engine's TeX subset is narrow. `\left`, `\right`, `\cdot`,
  `\text{}`, `\boxed`, `\quad`, escaped spaces — all rejected.

**Process:** the user works via `superpowers:subagent-driven-development`
(implementer → spec review → quality review). The quality review has been the
highest-value step; it found the verifier-bypass bug. Karpathy guidelines apply
(surgical changes, no speculative features).

## 6. Decisions already made — do not silently revisit

- **Verifier over model size** (§4.5). 10 steps at 99% each is only ~90% of
  solutions clean, and most of that error class is mechanically checkable.
- **No handwriting vision** (§5 Flow D). Ink is a drawing surface; the student
  states their answer. Confident misreading costs more trust than not reading.
  Re-entry path is constrained blanks, not free-form pages.
- **Model never computes coordinates.** It emits semantic steps; `board-layout`
  assigns positions. This is what makes layout testable without a key.
- **Two live brains maximum.** Latency is the binding constraint: ~1 model on
  the critical path, ~1 near it, others async or offline.
- **agency-swarm / make-it-heavy / LiCoMemory evaluated and declined** as
  dependencies — see [assessment](2026-07-31-external-tools-assessment.md).
  make-it-heavy's parallel-then-synthesise pattern is worth reusing for evals
  and diagnosis, offline only.
